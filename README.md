# 生猪期货基本面数据监控与决策系统

这是一个生猪期货基本面数据一站式跟踪与智能化决策分析系统。系统集成了大连商品交易所（DCE）生猪合约行情、全国瘦肉型肉猪出栏均价、饲料原料（玉米/豆粕）走势、能繁母猪宏观产能数据以及动物疫情通报与市场论坛舆情监控，自动校验市场供需并输出专家建议。

## 快速启动指南

### 1. 运行 PostgreSQL 数据库
系统使用 Docker Compose 管理 PostgreSQL 容器，以确保跨多进程的高并发与事务安全性。
```bash
# 启动数据库容器
sudo docker-compose up -d
```

### 2. 初始化与同步数据 (Seeding)
我们在 `backend` 中配备了数据迁移和自动化种子同步工具。数据同步需要使用已安装的 python 虚拟环境：
```bash
# 进入虚拟环境并运行初始化建表
venv/bin/python -m backend.init_db

# 从新浪财经及 AkShare 爬取历史/当日真实数据
venv/bin/python -m backend.seed_data
```

### 3. 开启 FastAPI 后端 API 服务
运行 Uvicorn 开发服务器，启动后端多接口以及后台数据调度器（在交易时段定时轮询最新合约价格）。
```bash
# 启动后端服务
venv/bin/python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
```
- 后端健康检查 / 智能决策 API 地址：`http://localhost:8000/api/expert/advice`

### 4. 开启 React 前端调试服务器
```bash
# 进入前端文件夹
cd frontend

# 安装依赖（如已安装可跳过）
npm install

# 运行 Vite 调试大屏
npm run dev -- --host 0.0.0.0 --port 5173
```
- 在浏览器中打开 `http://localhost:5173/` 即可访问主控制面板。

## 核心业务组件介绍

1. **宏观发改委政策警示状态**：基于当前现货猪粮比价，自动匹配过度下跌一/二/三级警戒（提示收储）或正常绿色区间。
2. **期现收敛走势图**：以“元/公斤”为统一度量衡，直观反映选定合约交割期的期现收敛情况。
3. **养殖利润与成本计算器**：支持保存参数至浏览器 `localStorage` 并能一键导出 `.txt` 详细模拟测算报告。
4. **决策雷达系统**：交叉校验“现货价变动”、“出栏均重”、“饲料物价”以及“疫病词频”，分发养殖端、中游屠宰、套保员针对性交易法则。
5. **前瞻舆情多维交叉印证系统**：通过多渠道（搜猪网、东方财富、同花顺等期货/股票/行业平台）实时抓取网络言论热词与交易情绪，并与兽药动保采购、饲料细分销量、省际物流调运和下游肉品深加工需求等物理层面实物指标进行多维度交叉背离印证，弥补官方宏观数据严重滞后性。
