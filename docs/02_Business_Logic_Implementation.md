# 核心业务逻辑实现 (Business Logic Implementation)

本系统的核心价值在于强大的数据获取能力以及多维度的智能分析模型。以下是系统中几个最关键业务模块的实现深度解析。

## 1. 自动化数据采集引擎 (Data Scraping Engine)

系统的生命线在于数据的及时性与准确性，该部分逻辑主要集中在 `backend/scraper.py`。

### 1.1 期货实时行情获取

*   **数据源**: 新浪财经行情接口 (`hq.sinajs.cn`)。
*   **实现原理**: 构建特定的 symbol 列表（如 `nf_LH2609` 代表主力合约，`nf_LH0` 代表连续合约）。通过 HTTP GET 请求获取原始文本数据，按逗号分隔解析出开盘、最高、最低、最新价、昨结等 10 余项关键指标。
*   **更新策略**: 若数据库中已存在同日同合约的数据则更新（Update），否则插入（Insert）。

### 1.2 现货与宏观基本面数据获取

*   **数据源**: AkShare 财经数据接口库。
*   **多维数据整合**:
    *   **现货价格 (`fetch_spot_prices`)**: 结合了长期指数数据（自 2015 年）和近 200 天的高频逐日数据。
    *   **基差计算 (`update_basis_values`)**: 基差 = (现货价 * 1000) - 期货主力收盘价。系统通过匹配同一日期的现货与期货 K 线数据，自动补全基差信息。
    *   **养殖成本与利润 (`fetch_breeding_indicators`)**: 通过抓取玉米（C0）和豆粕（M0）的期货价格作为饲料成本基准，结合固定参数（如料肉比、人工、折旧等），推算出实时的“自繁自养利润”和“外购仔猪利润”。
    *   **产能监控 (`fetch_swine_capacity`)**: 解析不同周期的能繁母猪存栏量，并根据生物学生长周期，通过算法平滑推演（Project forward）估算当期的生猪出栏量和定点屠宰场开工率。
    *   **前瞻多维舆情雷达 (`fetch_sentiment_radar`)**: 系统通过多渠道爬虫引擎（搜猪网、东方财富网期货频道、同花顺期货通）实时获取当下行业内及投资者讨论的最新文章和资讯，使用词频匹配机制对用药/动保、饲料销量、深加工需求、物流调运、疫病疫情、二育投机等 6 大前瞻维度进行词频和情绪评分，持久化至 `SentimentIndex` 数据库，从而能够有效交叉背离校验，侧面印证物理层面的生猪真实状况。

## 2. 专家决策雷达系统 (Expert Advice System)

`main.py` 中的 `get_expert_advice` API 是系统的“大脑”，负责生成具有实操指导意义的报告。

### 2.1 交叉验证逻辑

该模块提取最新的 5 维数据特征：**价格趋势**、**基差水平**、**养殖利润（猪粮比）**、**出栏均重**（推演值）、以及**疫病舆情指数**，并应用一系列硬编码规则进行市场状态的界定：

1.  **虚火/虚假繁荣 (Supply-Demand Divergence)**:
    *   *条件*: 现货趋势上涨 + 出栏均重过高 (>123kg) + 猪粮比处于盈利区间 (>6.0)。
    *   *判断*: 价格上涨主要由养殖端压栏惜售和二次育肥驱动，提示后期踩踏风险。
2.  **产能出清/见底 (De-capacity Bottoming)**:
    *   *条件*: 猪粮比持续低于 5.8 且 自繁自养利润深度亏损 (< -150元)。
    *   *判断*: 行业处于去产能中后期，长线面临多头拐点。
3.  **恐慌抛售 (Epidemic Panic Selling)**:
    *   *条件*: 现货趋势下跌 + 出栏均重过低 (<120kg) + 疫病词频高。
    *   *判断*: 砸出周期“黄金坑”，短期利空，中远期利多。
4.  **高成本挤压 (Cost Squeeze)**:
    *   *条件*: 玉米价格高位 (>2600元) + 养殖亏损。
    *   *判断*: 饲料成本侵蚀利润，被动加速去化。

### 2.2 动态建议分发

根据上述结论，系统分别向三个群体（养殖场户、中游屠宰加工、期货套保员）生成定制化的操作 Action（如：“逢高卖保”、“随杀随销”）。

## 3. 易经交叉决策预测模型 (Yijing Decision Engine)

系统创造性地在 `backend/yijing.py` 中引入了古典玄学算法与现代量化因子的融合，这是一种实验性的“另类数据”分析方法。

### 3.1 核心算法

*   **梅花易数 (Meihua Yishu)**:
    *   利用系统当前请求时间的年月日时计算数字，并通过“现货与期货的基差百分比”作为扰动因子加入运算。
    *   推演出本卦、互卦、变卦，并依据八卦的五行属性（金木水火土）推演“体用生克”关系，计算得分。
*   **六爻纳甲 (Liuyao Najia)**:
    *   将时间的秒数以及基本面量化指标（猪粮比、盈利状态、绝对价格）作为随机种子，生成六个爻象（老阴、少阴、少阳、老阳）。
    *   定位动爻、世应爻，结合爻辞吉凶赋予权重得分。
*   **综合量化因子**:
    *   引入纯量化指标（深度亏损计空，利润丰厚计多，现货升水计多）进行修正。

### 3.2 价格走势投影 (Price Projection)

将玄学算法计算出的 `total_score` 映射为方向标签（如“强势看多”、“震荡偏空”）。结合几何布朗运动（GBM）框架和波动率因子计算，推算出 1日、5日、10日后的预期价格置信区间（Mid, High, Low），并通过 API 返回给前端进行图形化渲染。

## 4. 前瞻性多维交叉验证算法与规则体系 (AI 逻辑参考)

为防止网络舆情数据存在虚假宣传或散户情绪偏差，系统引入了物理侧替代数据进行 **“背离印证”** 校验。AI 开发助手可直接基于以下预设规则进行异常状态检测与模型微调：

### 4.1 用药舆情 vs. 动保采购量背离校验

*   **指标定义**:
    *   舆情指数 $S_{med}$：监测“用药挺价舆情”词频得分（0 - 100 分）。
    *   实物采购 $V_{idx}$：猪瘟、蓝耳等强制免疫疫苗及抗生素采购景气度指数。
*   **异常警示规则 (Divergence Logic)**:
    $$\text{If } S_{med} > 65 \text{ and } V_{idx} < 45 \text{ for consecutive 5 days} \implies \text{Alert("防保虚高背离")}$$
    *   **AI 解释**: 表明网上对生猪用药防保的讨论热度极高，但上游兽药厂实际出货量严重萎缩。说明市场可能存在故意夸大疫情制造恐慌（空头砸盘），或养殖户实际补栏极低导致防疫投入停滞。

### 4.2 饲料消耗结构分析 (Feed Mix Ratios)

*   **指标定义**:
    *   母猪料比重 $R_{sow} = \frac{\text{sow\_feed}}{\text{overall\_feed\_volume}}$
    *   大猪料比重 $R_{fin} = \frac{\text{finisher\_feed}}{\text{overall\_feed\_volume}}$
*   **出栏重与二育（投机）印证**:
    *   当现货价格上涨，且 $R_{fin}$ 的 10 日均值环比增加超过 $15\%$，而能繁母猪存栏持平：
        $$\Delta R_{fin} > 0.15 \implies \text{Status("主动压栏惜售/二育泡沫累积")}$$
    *   **AI 解释**: 肥猪配合料销量异常暴增，代表场内大猪压栏不卖，或者大量中猪被买去进行“二次育肥”（把猪养得更重再卖），预示着 30-45 天后将迎来集中的出栏踩踏，现货主力合约将面临下行压力。

### 4.3 下游深加工与商用餐饮肉类抵制 (Demand Destruction)

*   **指标定义**:
    *   深加工比重 $D_{proc}$：猪肉深加工制品（如火腿、培根）需求量。
    *   餐饮消费量 $D_{cat}$：商用餐饮、食堂等肉类采购吨数。
*   **消费传导校验**:
    *   当现货价 $P_{spot} > 18.0$ 元/公斤，若发现 $D_{cat}$ 环比下降 $> 8\%$ 且 $D_{proc}$ 保持稳定：
        $$\text{Alert("高价消费抑制")}$$
    *   **AI 解释**: 表明终端消费者对高价生猪产生抵制，餐饮渠道转而采用鸡肉等替代蛋白，而深加工制品（由于配方和生产周期固定）表现钝化。这预示着现货上涨已进入尾声（消费端无法承接）。

### 4.4 跨省调运与病死无害化（疫病突发校验）

*   **指标定义**:
    *   检疫车次 $Q_{cert}$：跨省调运检疫票发放张数。
    *   无害化量 $M_{waste}$：病死猪无害化处理量（吨）。
*   **异常拦截逻辑**:
    *   若“非瘟/腹泻恐慌舆情”得分 $S_{dis} > 70$，且 $M_{waste}$ 环比暴增 $> 25\%$，同时运费指数 $I_{freight}$ 下跌：
        $$\text{Confirm("局部严重疫病出清")}$$
    *   **AI 解释**: 证实了非理性恐慌的真实性，抛售行为导致物流挤兑、病死量大增，同时因为抛售者急于变现，运猪车供大于求导致运费反跌。此时期现货短期将大跌，但中长线产能大幅去化后将迎来暴涨行情。
